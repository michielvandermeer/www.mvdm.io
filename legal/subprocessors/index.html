Subprocessor list

Effective 28 August 2026. A later edit replaces this page in place.

This page lists third parties mvdm.io uses to process personal data when providing Compliance. It is the living subprocessor list referenced by the Data Processing Agreement.

Current subprocessors

  • Hetzner — application and database hosting in the EEA.
  • Stripe — payment processing (United States).
  • Cloudflare Email — transactional and operational email delivery (United States).
  • xAI — processes Assistant conversation content so the Compliance assistant can run (United States).
  • Anthropic — processes content for import extraction and snapshot prose features (United States).

Notes

Self-hosted tooling that does not hand Customer ISMS personal data to a third party is not listed here. Edits replace this page in place; the Data Processing Agreement explains how replacements are accepted through continued use of Compliance.
